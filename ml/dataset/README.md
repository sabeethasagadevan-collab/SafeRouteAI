# Dataset instructions

No real labelled accident/landslide/traffic dataset is bundled. This is intentional: synthetic labels cannot demonstrate real-world accuracy.

For a valid model, obtain a documented dataset from an official transport, disaster management, or research source. Record licence, geographic coverage, timestamp, label definition, feature units, and missing-value handling. Use time-based train/test splitting where the prediction target is temporal. Do not use future information as a feature.
